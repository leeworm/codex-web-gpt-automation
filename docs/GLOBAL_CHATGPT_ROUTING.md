# Shared ChatGPT routing

New work follows [the common automation policy](AUTOMATION_POLICY.md).
Projects reference that policy instead of copying mode-specific instructions.
This document does not authorize changing a host's global configuration.

Use one mission-based execution flow. Planning, research, review, implementation,
and editing describe the requested work, not separate engines or mandatory
stage chains. Preserve the configured native commander and user-approved
delegation. Do not restore removed CGW routing.

## Natural route selection

With the managed global policy installed, native Codex handles short,
mechanical, single-file, or quick diagnostic work directly. It automatically
chooses the ordinary Oracle route for work that is repository-wide,
multi-module, long-running, root-cause oriented, spans many files/logs/web
sources, combines implementation with tests/E2E, or is likely to take roughly
15 minutes or more. The user does not need to repeat "use Oracle" for those
already-authorized tasks.

The ordinary automatic Oracle route explicitly selects **GPT-5.6 Sol**, then
**High** (`extended`), and uses the registered `@codex` DevSpace app with the
exact approved project root. Use temporary chats with personalization
automatically enabled and confirmed before submission. Preserve the same owned
tab through capture, persist the complete result, and only then close it. On
uncertainty recover the exact same run; never automatically resend.

Pro, Extra High, Web Multi, comprehensive, and historical compatibility routes
are outside automatic routing. Use them only when the user explicitly requests
that route or an existing persisted run requires exact historical recovery.

There is no per-project or daily qualification chain, required audit nonce,
three-receipt sequence, compulsory final marker, or archive/restore stage.
Root access, authentication, task ownership, actual model selection, and durable
result capture remain essential. Project tests and domain safety rules remain
in force.

Historical modes and recovery records retain their original meaning. They are
not advertised or selected for new work and are never automatically adopted.
